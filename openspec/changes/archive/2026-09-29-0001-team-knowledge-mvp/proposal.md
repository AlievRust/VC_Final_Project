# Система знаний команды

## Зачем

Нужен учебный MVP, в котором команда загружает текстовые документы и находит основания для ответа по ним. Исходное задание: `1st_prompt.md`.

## Что входит

- Серверная панель документов, вопросов и истории.
- API документов, гибридного поиска и, после согласования политики evidence, ответов с источниками.
- PostgreSQL как единственное постоянное хранилище; pgvector, BM25, RRF.
- Запуск через Docker Compose с единственной внешней точкой входа Caddy `:80`.
- Аудит операций, диагностические данные поиска и контрольный набор.

Не входят возможности из раздела Non-goals исходного задания.

## Приёмка

После всех checkpoint: 5 документов, 10 вопросов; 7 подтверждённых ответов с источниками и 3 честных отказа с `needs_review=true`; история и аудит сохраняются. Порог evidence согласуется с оператором после CP3 и до CP4.
