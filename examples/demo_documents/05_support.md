# Поддержка внутренних пользователей

Обычные обращения принимает команда поддержки в рабочие дни с 09:00 до 18:00 по московскому времени. Обращение создаётся через внутреннюю форму поддержки.

Для срочной проблемы пользователь звонит дежурному по номеру 777. Дежурный регистрирует обращение после звонка.
