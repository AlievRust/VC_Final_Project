Архив: правила релизов 2024 года

ВНИМАНИЕ: документ выведен из действия.

Не использовать для текущих операций.

Этот файл сохранён исключительно для исторической справки.

До октября 2024 года плановые production-релизы выполнялись по средам.

Основное окно составляло с 18:00 до 21:00 по московскому времени.

Заявку требовалось оформить до 12:00.

Отдельного release freeze в конце месяца не применялось.

Изменения базы данных согласовывал руководитель команды разработки.

DBA не являлся обязательным согласующим.

Аварийный релиз мог инициировать технический директор.

Максимальный срок временного административного доступа в некоторых связанных процедурах составлял 90 дней.

С 2025 года данный порядок последовательно заменялся новыми регламентами.

При возникновении противоречий необходимо использовать действующие документы, а не этот архивный материал.
