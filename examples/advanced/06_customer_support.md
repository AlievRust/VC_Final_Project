Работа клиентской поддержки

Стандартные обращения клиентов обрабатываются в рабочее время с 09:00 до 18:00 по московскому времени.

Для обычного клиента целевое время первого ответа — четыре рабочих часа.

Для клиентов с приоритетным SLA целевое время первого ответа — один рабочий час.

Экстренная телефонная линия предназначена только для критических ситуаций, связанных с недоступностью сервиса или невозможностью выполнения ключевой операции.

Номер экстренной линии: +7 495 555-01-30.

Экстренная линия работает круглосуточно.

Использование экстренной линии для обычных консультаций, вопросов о документах, тарифах или статусе стандартного обращения не допускается.

Обращение клиента по экстренной линии не означает автоматического присвоения внутреннего приоритета P1.

Категорию инцидента определяет техническая команда по регламенту управления инцидентами.

При массовом техническом инциденте официальное уведомление клиентской поддержки инициирует incident manager.

Сотрудник поддержки может передать клиенту опубликованный статус инцидента, но не должен самостоятельно прогнозировать время восстановления, если оно не подтверждено технической командой.

Компенсации, возвраты денежных средств и штрафы данным регламентом не определяются.
